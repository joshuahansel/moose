# HSCoupler2D2DRadiationAC

`HSCoupler2D2DRadiationAC` is the [ActionComponent.md] version of the
[HSCoupler2D2DRadiation](HSCoupler2D2DRadiation.md) component, used with `type = HSCoupler2D2DRadiation` in the
`[ActionComponents]` block. See [HSCoupler2D2DRadiation](HSCoupler2D2DRadiation.md) for its documentation.
